My Achievements
================

این پروژه یک اپ ساده‌ی Achievement برای اندروید است.

قابلیت‌های نسخه 1.0:
- ساخت Achievement
- عنوان و توضیحات فارسی
- Bronze / Silver / Gold / Platinum
- Completed / Not completed
- ویرایش و حذف
- ذخیره دائمی روی گوشی
- جابه‌جایی کارت‌ها با نگه‌داشتن و کشیدن بالا/پایین
- ظاهر تیره و ساده شبیه اپی که فرستادی

ساخت APK:
1) کل پوشه را در GitHub به صورت یک repository آپلود کن.
2) فایل .github/workflows/build.yml خودش APK را می‌سازد.
3) بعد از تمام شدن build، از Actions > آخرین اجرای موفق > Artifacts فایل MyAchievements-debug-apk را دانلود کن.
4) فایل APK را روی گوشی نصب کن.

این پروژه عمداً dependency خارجی ندارد تا build ساده‌تر باشد.
